# Chikin Bot

Telegram-екосистема для контролю відкриття та закриття торгових точок, запізнень, касових звітів, кущів і ролей користувачів.

## Основні модулі

- ранковий чекін торгової точки;
- контроль кластерів 07:00, 08:00, 09:00 і 10:00;
- фіксація запізнень;
- вечірнє закриття з фотографією чека;
- підрахунок каси по ТТ, кущу та мережі;
- ролі ROOT_ADMIN, DIRECTOR, BUSH_ADMIN, LION і STORE_USER;
- Telegram deep-link запрошення;
- Excel-звіти за день, тиждень, місяць і довільний період;
- автоматичні зведення в Telegram-групі;
- PostgreSQL, Alembic, scheduler, Docker і Railway.

Повне пояснення структури міститься у `PROJECT_TREE.md`.
